**Title:** Decision Origami — GenLayer Spinner

## Notes / Description

Decision Origami is a production-ready GenLayer loading spinner built from the mark itself. The two outer wings fold with perfectly mirrored timing, the center resolves only after they seat, and the exact GenLayer mark holds as the finality state before the motion reverses. Delivered as a zero-dependency animated SVG with reusable CSS and an optional React/TypeScript wrapper. It uses `currentColor` for light/dark surfaces, loops smoothly, includes reduced-motion support, and is tested at 16, 20, 24, 32, 48 and 64px. The repository also includes a live playground and implementation notes so it can be evaluated and integrated quickly.
